# Bharat-Data-Project
This is a community-driven, open-source project to map out India's complete political, historical, and geographical data from 1947 to the present.

Our Goal: We are building a free, accessible database containing state histories, district data, past and present ministers, and military officials.

How to Help: We are looking for Python developers to build data scrapers, and data enthusiasts to help manually compile historical records. Check our "Issues" tab to see what needs to be done.
